# AllertaMeteo

Sistema di monitoraggio e notifica delle allerte meteorologiche e criticità idrogeologiche pubblicate dal Dipartimento di Protezione Civile.

## Componenti

- `alert_script/` - Script Python per il monitoraggio allerte, invio notifiche Telegram e API server
- `alert_web/` - Interfaccia web per la visualizzazione delle allerte

## Funzionalità

- Monitoraggio automatico dei bollettini di criticità idrogeologica
- Notifiche Telegram in tempo reale
- API REST per consultazione dati
- Interfaccia web di visualizzazione
- Supporto per iscrizioni personalizzate
- Download e archiviazione PDF dei bollettini CFD
